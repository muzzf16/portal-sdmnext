## PANDUAN CEPAT (QUICK START)

1. **Clone repository:**
   ```bash
   git clone <repository-url>
   cd sistem-manajemen-sdm
   ```

2. **Install Dependensi:**
   - **Backend:**
     ```bash
     cd apps/backend
     npm install
     ```
   - **Frontend:**
     ```bash
     cd apps/frontend
     npm install
     ```

3. **Menjalankan Aplikasi (Lokal):**
   - **Backend:**
     ```bash
     cd apps/backend
     npm run dev
     ```
     Server akan berjalan di `http://localhost:3333`

   - **Frontend:**
     ```bash
     cd apps/frontend
     npm run dev
     ```
     Aplikasi frontend akan tersedia di `http://localhost:5173`
